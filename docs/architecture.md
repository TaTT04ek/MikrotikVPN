# Архитектура

- Интерактивный установщик RouterOS выбирает смонтированный диск, принимает архив образа и предлагает отдельную сеть `172.30.55.0/30`. Он создаёт VETH, том `/data`, профиль окружения, локальные правила доступа и таблицу маршрутизации. Маркировка трафика включается после запуска контейнера для указанных IPv4-клиентов и выбранных Wi‑Fi-портов.
- RouterOS определяет IPv4-клиентов по списку `mikrot-vpn-clients` и по меткам пакетов, поступивших с Wi‑Fi-портов доверенных мостов. Правила маршрутизации отправляют подходящий трафик на VETH контейнера. Отдельная таблица маршрутизации содержит маршрут через VETH с проверкой шлюза.
- TUN принимает IPv4 TCP и UDP. Mihomo сопоставляет трафик с правилами по сервису, домену, IP назначения и источника. Правило VPN передаёт решение подправилу по типу сети. TCP использует MIKROT-VPN, UDP использует MIKROT-VPN-UDP. Прямые правила выбирают DIRECT для обоих протоколов.
- Менеджер опрашивает локальный API Mihomo через отдельный URL-тест каждого узла и читает признак поддержки UDP. bestNode применяет задержку и порог к каждому выходу, отфильтровывает узлы без UDP для группы UDP и выбирает DIRECT при отсутствии подходящих узлов. Запросы проверки не меняют состояние после смены ревизии конфигурации.
- Веб-панель показывает встроенный каталог через GET /api/services. Одно упорядоченное правило SERVICE сохраняет ID пресета, а coreConfig разворачивает набор точных имён и суффиксов в локальный Mihomo rule provider. По желанию пользователь включает DNS в режиме redir-host на порту 53. Он запоминает соответствия между доменами и реальными IP из DNS-ответов для клиентов, использующих DNS контейнера.
- Менеджер загружает URL-подписки и принимает отдельные ключи подключения, объединяет уникальные узлы и применяет конфигурацию через локальный API Mihomo. Последнее применённое состояние хранится в `/data/state.json`. При ошибке обновления подписки сохраняется последний набор узлов этого источника.
- Веб-панель использует JSON API Go-процесса. В статус попадают название, протокол, задержка узла и счётчики входящего и исходящего трафика интерфейса основного IPv4-маршрута контейнера. Панель рассчитывает скорость из соседних замеров и хранит историю графиков в памяти вкладки. Ссылка подписки и параметры доступа остаются на сервере.
- При запуске выходы TCP и UDP используют DIRECT до первого успешного цикла проверки. Если ядро останавливается, управляющий процесс завершает контейнер. RouterOS может его перезапустить или вернуть трафик в основную таблицу, когда VETH перестаёт отвечать.
