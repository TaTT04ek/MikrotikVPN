# Совместимость MikroTik VPN

Проверка сборки подтверждает, что образ собран для архитектуры. Статус модели обновляется после установки и испытания на самом устройстве.

| Устройство | Архитектура образа | Архив | Статус |
| --- | --- | --- | --- |
| MikroTik hAP ac³ | ARMv7 | `mikrot-armv7.tar` | Первый аппаратный кандидат. Предстоит испытать с USB ext4. |
| MikroTik hAP ac² | ARMv7 | `mikrot-armv7.tar` | Кандидат. Предстоит проверить запуск и потребление памяти. |
| MikroTik hAP ax³ | ARM64 | `mikrot-arm64.tar` | Кандидат. Предстоит испытать на устройстве. |
| MikroTik RB5009UG+S+IN | ARM64 | `mikrot-arm64.tar` | Кандидат. Предстоит испытать на устройстве. |
| MikroTik hEX refresh (E50UG) | ARMv5 | `mikrot-armv5.tar` | Кандидат. Для EN7562CT MikroTik указывает ограничение ARMv5 для контейнеров. |
| RouterOS CHR x86-64 | AMD64 | `mikrot-amd64.tar` | На RouterOS 7.24.6 проверены установка с диска, перезагрузка и доступ к API панели. На локальном HTTPS-стенде проверены скачивание скрипта и образа через перенаправление и запуск с пользовательской подсетью. |

`mikrot-armv6.tar` собирается для устройств с соответствующей архитектурой контейнеров. Конкретных проверенных моделей для ARMv6 пока нет. Для каждой модели проверяйте `architecture-name`, версию RouterOS, наличие пакета `container` и смонтированного диска. [Ограничения Container](https://manual.mikrotik.com/docs/containers/) · [hAP ac³](https://mikrotik.com/product/hap_ac3) · [hAP ac²](https://mikrotik.com/product/hap_ac2) · [hAP ax³](https://mikrotik.com/product/hap_ax3) · [RB5009](https://mikrotik.com/product/rb5009ug_s_in) · [hEX refresh](https://manual.mikrotik.com/hardware/hex-refresh/)

## Что проверить на устройстве

- Установка на смонтированный диск, открытие панели и повторный запуск после перезагрузки.
- Импорт подписки, выбор доступного узла, сохранение настроек и правил после перезагрузки.
- TCP через VPN, UDP или QUIC через подходящий узел и прямой выход при отказе всех узлов.
- Одно правило для известного сервиса и один прямой маршрут с того же клиента.
- Свободная память роутера во время распаковки, запуска и под нагрузкой.

Записывайте модель, точную версию RouterOS, архитектуру, тип накопителя и результат каждого пункта. В стабильный список поддержки попадают испытанные модели.
